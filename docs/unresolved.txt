# and DSBN directly — a login, not a public board. Same bucket as Mohawk Career Ready.
# Worth revisiting only if ATE ever exposes a public search.

# === B. KNOWN VENDOR, ADAPTER NOT WRITTEN YET ===================================

# --- Dayforce (11) ------------------------------------------------------------
# Alectra, Burlington Hydro, Sinai Health, Women's College, Infrastructure Ontario,
# Conservation Halton, TRCA, Sofina, Tigercat, Synaptive, eSentire.
# The candidate portal is a Next.js app whose __NEXT_DATA__ carries only site-info —
# the postings arrive in a later call this run did not capture. Find that call with
# the CDP recorder (the same trick that found hiring.cafe's SSR endpoint) and this is
# probably another plain JSON adapter. Highest count left.

# --- Taleo Business Edition (8) -----------------------------------------------
# St. Joseph's Health System, Town of Oakville, Oakville Public Library, City of
# St. Catharines, Niagara College, OCAD, Seneca, Canadian Red Cross.
# tre.tbe.taleo.net/tre01/ats/careers/v2/searchResults?org=<ORG>&cws=<N> is plain
# server-rendered HTML — requisition ids read straight out of it (5, 10, 2 and 10
# requisitions on the four tested). Easiest remaining win; no browser needed.

# --- Taleo Enterprise (2) — but one of them is HHS ----------------------------
# Hamilton Health Sciences and Humber Polytechnic. The REST endpoint is
# careersection/rest/jobboard/searchjobs?portal=<id>, and Humber's URL hands over its
# portal id (12100010168). HHS does not: its jobsearch.ftl ships <input name="portal"
# value=""> and fills it in by script. Two employers only, but HHS is the largest
# employer in Hamilton — worth chasing for that alone.

# --- Oracle Recruiting Cloud (6) ----------------------------------------------
# CAMH, Trillium Health Partners, Definity, WSIB, Linamar, Metrolinx.
# fa-*.oraclecloud.com/hcmUI/CandidateExperience — has a documented public REST
# endpoint (recruitingCEJobRequisitions). Not yet tried.

# --- MediSolution eRecruit (5) ------------------------------------------------
# Joseph Brant, Lakeridge Health, Niagara Health, Durham Region, Peel Regional Police.
# An Ontario hospital HR product (meta author: "MediSolution (2009) Inc."), ASP.NET,
# server-rendered, with real posted AND closing dates. Ten results a page behind a
# WebForms postback (__EVENTTARGET=...gvwSearchResults, __EVENTARGUMENT=Page$2, plus
# __VIEWSTATE and __EVENTVALIDATION) — doable with a cookie jar, just fiddly. Its
# RSS.aspx is broken: 27 empty <item> tags nested inside each other, served as HTML.
# (Wescast Industries is a false positive — "eRecruit" appeared in unrelated markup.)

# === D. NO VENDOR AT ALL (114) ==================================================
# Hand-built careers pages, one scraper each — which is exactly what the adapter
# model exists to avoid. Not worth it wholesale. But note WHERE they cluster:
#   22 libraries   14 hospitals   12 municipal   9 universities   9 tech
#    7 school boards   7 independent schools   6 industry   5 police
# The libraries are the striking one. Hamilton, Burlington, Milton, Halton Hills and
# Brantford all hand-roll their careers page — hpl.ca/jobs, bpl.on.ca/about/careers,
# hhpl.ca/careeropportunities. Small, static, and each would be perhaps 20 lines.
# If any group here is worth bespoke scrapers, it is the local libraries: tiny IT
# teams, few postings, and effectively no competition for them.
