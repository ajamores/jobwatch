#   ats  host  label  [key=value,...]        (two or more spaces between fields)
#
#   where=<town>  works for any vendor. For boards that print a building ("Town Hall",
#                 "Lake Erie Works") instead of a place, it tells the @ filter which
#                 town the employer is in. No commas in the value.
#

# only use a handful of vendors between them.

# checking whether a posting went up today or last year. "New" means new to seen_sites.json.
